Mỗi hồ sơ là một thư mục Chrome riêng (cookie, đăng nhập, tiện ích tách biệt). Sao lưu cả thư mục này để giữ toàn bộ hồ sơ.

Xác nhận

Proxy VPN (ExpressVPN trên VPS)

Mỗi proxy là một kết nối ExpressVPN riêng chạy trên VPS của bạn → mỗi hồ sơ Chrome đi ra một IP khác nhau. ExpressVPN giới hạn số thiết bị kết nối cùng lúc (thường 8), mỗi proxy tính là 1 thiết bị.

Tài khoản ExpressVPN (cấu hình thủ công)

Lấy tại expressvpn.com → đăng nhập → Set up other devices → Manual Configuration → tab OpenVPN → copy Username và Password (khác mật khẩu đăng nhập web). Thông tin chỉ lưu trên VPS của bạn.
