Quản lý Chrome

Phần mềm quản lý hồ sơ Chrome cho Windows 10/11
⬇ Tải về (QuanLyChrome.zip)
  1. Giải nén file zip vào một thư mục cố định, ví dụ D:\QuanLyChrome (không chạy trực tiếp trong file zip).
  2. Mở ChromeManager.exe. Nếu Windows cảnh báo: bấm More info → Run anyway.
  3. Bấm Đồng bộ ở góc trên → Đăng nhập với máy chủ:
    https://49-236-211-75.sslip.io

Máy cần cài sẵn Google Chrome.
