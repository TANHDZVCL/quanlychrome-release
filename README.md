# Quản lý Chrome — kho phát hành (riêng tư)

- `release/` — bản phần mềm mới nhất (`ChromeManager.exe`, `QuanLyChrome.zip`, `version.json`).
  VPS tự lấy về trang tải mỗi 10 phút; các máy thấy nút **⬆ Cập nhật**.
- `source/` — mã nguồn (phần mềm Windows, máy chủ đồng bộ, dịch vụ Proxy VPN).
- `vps/` — script cài trên VPS để tự lấy bản mới từ repo này.
